## ✨ 一句话介绍

PhotoSwipe 读取 iPhone 相册，你只需要**全屏滑动**：上滑进待删队列、下滑标记喜欢、左右翻页。攒够了到垃圾桶里一次性确认删除——**能提前看到这批照片能释放多少空间**。

## 🔥 核心亮点

| | 亮点 | 说明 |
|:---:|---|---|
| 🗑️ | **待删队列 + 空间预估** | 上滑不删除，先攒队列；删除前显示可释放空间，支持单张撤回，进入系统「最近删除」30 天可恢复 |

| 📏 | **按体积排序** | 文件大小从大到小，专治占空间的视频（系统相册做不到） |
| 🎬 | **视频全屏播放** | 缩放、手势、进度，都在滑动的流程里 |

## 🤔 起因

整理两万余张照片时，系统相册只能逐张打开、逐张删除，效率无法接受。

## ✋ 功能

### 分类

分类结果直接读取 iOS 的智能相簿（`PHAssetCollection`），与系统相册「相簿」页中的分类一致，不做二次筛选。

| 分类 | 内容 |
|---|---|
| 全部照片 | 整个图库，按拍摄时间倒序 |
| 自拍 | 前置摄像头拍摄的照片 |
| 截屏 | 截图 |
| 实况照片 | Live Photo |
| 视频 | 所有视频，可全屏播放 |
| 全景 | 全景照片 |
| 人像模式 | 带景深信息的照片 |
| 喜欢 | 已在系统相册中标记喜欢的照片 |

### 手势

| 手势 | 行为 |
|---|---|
| 左右滑动 | 上一张 / 下一张，跟随手指连续分页 |
| ⬆️ 向上滑动 | 加入待删队列，**不立即删除** |
| ⬇️ 向下滑动 | 加入「喜欢」；再次下滑可取消 |
| 双指捏合 | 放大查看细节，放大后拖动只平移图片 |
| 双击 | 在 1× 与 2.5× 之间切换 |
| 点击标题旁箭头 | 展开四列缩略图总览，点任意一张回到该位置 |
| 点击视频 | 全屏播放 |

### 待删队列

> [!NOTE]
> **设计取舍**：删除不可逆，因此不绑定在最容易误触的手势上。手势只负责产生意图，执行集中在最后一次确认。

向上滑动不会删除照片，只把照片标识写入本地队列。右上角垃圾桶显示数量，打开后顶部先给出**这批照片合计能释放多少空间**；单张可撤回（立即回到浏览列表原位），也可一次删完。删除经系统确认后单次提交，照片进入「最近删除」，30 天内可恢复。队列本地持久化，重启设备不丢失。

### 排序

任意分类内可切换：默认（最新优先）、文件从大到小、从小到大。选择会被记住，按体积排序时标题下方显示实际大小。

### 智能整理

首页四个入口，对应四种「不知道从哪下手」的场景：

| 入口 | 做什么 | 需要分析 |
|---|---|:---:|
| 相似 / 连拍 | 把长得像的照片和连拍自动编成组 | ✅ |
| 按月整理 | 「2023 年 5 月 · 486 张」，整月进入清理 | — |
| 过期截屏 | 90 天前的截图单独成组 | — |
| 可能拍糊 | 自动挑出明显虚焦的照片，按糊的程度排序 | ✅ |

**整组处理**：滑到想留的那张，点「保留这张，其余 7 张待删」，同组其余全部进队列，自动返回。**拍糊角标**：判定虚焦的照片右上角会贴「可能虚焦」标签，仅提示不阻塞。

## 🔬 技术说明

- **分类采用系统智能相簿**：判定完全交由 `PHAssetCollection` 的 `smartAlbum` 完成，与系统相册结果完全一致。
- **删除后重建索引**：`PHFetchResult` 删除后索引会变化，维护独立数组重新计算有效范围，只渲染当前页前后各一页。
- **图片按需加载与预取**：内存中同时只保留 3 个图片请求，配合上限 120MB 的 `NSCache`。
- **文件大小走非公开 API**：PhotoKit 未提供该属性，从 `PHAssetResource` 通过 KVC 读取，取值前用 `responds(to:)` 判断。
- **相似照片用感知哈希（dHash）**：64×64 灰度 → 9×8 网格 → 64 位指纹，汉明距离 ≤10 视为相似。
- **两两比较分桶截断**：5000 张全量比较是 1250 万次，按 64 位指纹切 4 段 16 位分桶后降到几万次；单桶超 40 张直接跳过。
- **连拍不依赖哈希**：直接用系统原生的 `PHAsset.burstIdentifier` 分组，准确率最高。
- **拍糊用拉普拉斯方差**：阈值 20，偏保守——宁可漏判，不误标正常照片。
- **分析不下载 iCloud 原图**：缩略图请求关闭 `isNetworkAccessAllowed`，避免悄悄消耗数 GB 流量。
- **工程由 XcodeGen 描述**：仓库不含 `.xcodeproj`，编译时由 `project.yml` 现场生成。

## ⚠️ 已知限制

- **「自拍」范围由系统判定**：仅含前置摄像头拍摄的照片，与系统相册结果相同。
- **iCloud 照片首次加载较慢**：需临时拉取，属于网络与存储状态。
- **七天需重新签名**：免费 Apple ID 的通用限制。
- **相似与拍糊分析有范围**：默认只分析最近 5000 张、且本机已有缩略图的照片，结果本地缓存、增量补算。
- **拍糊判定可能漏判**：阈值偏保守，轻微手抖可能不在列表内。
- **未上架 App Store**：定位是个人使用的工具。
